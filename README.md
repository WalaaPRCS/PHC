# نظام الرعاية الصحية الأولية — الهلال الأحمر الفلسطيني

تطبيق ويب عربي لإدارة العيادات والسجل السريري الموحد، مع صيدلية ومختبر وتطعيمات وإحالات ومشاريع ممولة وطاقم العيادات. يتكون من واجهة ويب وخدمة API وخادم PostgreSQL مستقل، ويمكن تشغيلها على خادم المنظمة أو بيئة Docker/Coolify.

## التشغيل المحلي أو على خادم

1. ثبّت Docker Engine وملحق Docker Compose.
2. شغّل النظام مباشرة؛ لا يلزم تجهيز ملف `.env` أو إدخال أسرار في Coolify:
   ```sh
   docker compose up -d --build
   ```
3. افتح الرابط. في أول زيارة يظهر نموذج إنشاء مدير النظام؛ أدخل الاسم واسم المستخدم وكلمة مرور قوية مرة واحدة.
4. افحص `/api/v1/health` للتأكد من اتصال التطبيق بقاعدة البيانات.

تبقى قاعدة PostgreSQL ومفاتيح التشفير في volumes دائمين. لا تحذفها باستخدام `docker compose down -v`؛ حذفها يمسح قاعدة البيانات ومفاتيحها. لا ترفع نسخة قاعدة بيانات إلى GitHub. عند النشر خلف نطاق عام، فعّل HTTPS من خلال الوكيل العكسي في Coolify أو Nginx، وافتح الرابط أول مرة من جهاز موثوق لإنشاء حساب المدير.

## مكونات البيانات

تتضمن الهجرة الأولى جداول منظمة للعيادات والخدمات والموظفين والمشاريع ومؤشراتها وتغطية الخدمات والمرضى والزيارات والإحالات والأدوية والأرصدة والصرف وطلبات المختبر والتطعيمات والمستخدمين والجلسات والتدقيق وخرائط المعرّفات الخارجية. توجد طبقة `app_records` انتقالية لتشغيل الواجهة الحالية أثناء ترحيل كل شاشة إلى الجداول المنظمة.

رقم ملف المريض (`patient_number`) ثابت على مستوى النظام. يُخزن رقم الهوية مشفرًا، ويُستخدم HMAC منفصل للمطابقة. لا تخزن الواجهة كلمة مرور أو رمز جلسة في Local Storage. تعرض العيادة المسندة للمستخدم سجلاتها، مع ملخص أحدث زيارة خارج نطاقها عبر البحث المصرح به.

## الدخول والصلاحيات

- `system_admin`: العيادات والمستخدمون والمشاريع والكتالوج المركزي للأدوية.
- `clinic_admin`: إدارة تشغيل العيادة ضمن العيادات المسندة.
- `clinician`, `reception`, `pharmacist`, `lab_technician`, `viewer`: صلاحيات محددة لكل مورد وعيادة.
- تظهر شاشة إعداد لمرة واحدة لإنشاء أول مدير داخل النظام. بعد ذلك تُغلق تلقائيًا ولا يمكن إنشاء مدير أول آخر.
- كلمات المرور مخزنة باستخدام scrypt؛ الجلسة في Cookie من نوع HttpOnly وSameSite.
- صرف الدواء معاملة ذرية تتحقق من المخزون وتحدثه وتربط الدواء بزيارة وملف المريض.

## التطوير والاختبارات

```sh
npm install
npm test
npm start
```

`npm start` ينفذ ملفات الهجرة أولًا، ثم يبدأ الخدمة. يتطلب التشغيل `DATABASE_URL` وبقية المتغيرات الواردة في `.env.example`.

## الربط مع الأنظمة الأخرى

تفاصيل نماذج البيانات وعقود API في [`docs/INTEGRATION.md`](docs/INTEGRATION.md) و[`docs/DATA_MODEL.md`](docs/DATA_MODEL.md). كل المسارات تحت `/api/v1`، وتحتوي الاستجابات على `requestId`. تستخدم سجلات التطبيق معرّفات ثابتة، وتوفر `integration_systems` و`integration_identity_map` ربطًا صريحًا بين معرّف السجل المحلي ومعرّف النظام المصدر وإصداره. لا تستخدم أسماء الأشخاص أو العيادات كمعرّفات تبادلية.

## حالة النشر

المستودع يحتوي على الشيفرة ومخطط PostgreSQL وخدمة Docker Compose. تصبح قاعدة البيانات الفعلية متاحة بعد تشغيل الحزمة على خادم؛ مستودع GitHub وحده لا يشغّل قاعدة بيانات.
