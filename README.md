# نظام عيادات الرعاية الأولية — الهلال الأحمر الفلسطيني

هذه نسخة معاينة ثابتة للنظام، وتشمل واجهات إدارة العيادات والمشاريع والخدمات والمرضى والزيارات والصيدلية والمختبر والتطعيمات والإحالات.

## تشغيل المعاينة

افتح `dist/index.html` مباشرة في المتصفح، أو قدّم مجلد `dist` عبر أي خادم ملفات ثابت.

تستخدم المعاينة بيانات اصطناعية للتوضيح وتحفظ تغييراتها محليًا في المتصفح. هذا المستودع لا يحتوي خادمًا خلفيًا أو قاعدة بيانات مشتركة أو إعدادات دخول إنتاجية؛ يلزم تطوير وربط هذه المكونات قبل الاستخدام التشغيلي.

الشعار المستخدم في المعاينة هو `dist/prcs-logo.png`. إعداد الاستضافة موجود في `.openai/hosting.json`.
